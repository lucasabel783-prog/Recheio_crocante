# 🥐 Recheio Crocante

Landing page de uma padaria/pastelaria, feita para praticar os meus conhecimentos de **HTML, CSS e JavaScript**.

O site simula a presença online de um negócio local, com secções de produtos, horário, localização e avaliações de clientes.

## ✨ Secções

- **Início** — apresentação do negócio
- **Produtos** — galeria de doces e destaque para os mais pedidos (pastel de nata, bolo de chocolate, pão fresco)
- **Sobre** — apresentação da pastelaria
- **Horário** — horário de funcionamento com indicador de aberto/fechado em tempo real
- **Contacto** — morada, telefone, redes sociais, mapa incorporado, botões de WhatsApp e "como chegar"
- **Avaliações** — carrossel de reviews (anterior/seguinte), com dados vindos de `reviews.json`

## 🚀 Como usar

Basta abrir o `index.html` no navegador — não é necessário instalar nada.

Para correr localmente:

```bash
git clone https://github.com/lucasabel783-prog/Recheio_crocante.git
cd Recheio_crocante
```

Depois é só abrir o `index.html` no navegador de sua preferência.

## 🛠️ Tecnologias usadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e layout
- **JavaScript** — indicador de horário em tempo real, carrossel de avaliações
